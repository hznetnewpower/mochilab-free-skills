# 客户反馈主题整理

## 能帮你做什么

按用户指定的关键词主题整理反馈，支持多标签并保留未归类项，不臆测个人属性。

## 直接这样说

安装后，在聊天里直接描述需求，或者贴上资料、上传文件。

**“把这些客户反馈按速度、账单和其他问题整理一下。速度先看“慢、卡、延迟”，账单看“发票、扣费”；有拿不准的单列出来。”**

## 你需要提供什么

提供反馈记录和希望使用的主题；也可以让助手先提出关键词供你确认。

不用照着固定格式填写；缺少关键信息时，助手会用日常语言追问。

## 你会得到什么

得到各主题数量、原始反馈编号和未归类项。

助手会用清楚的文字解释结果，有生成文件时提供文件位置或下载链接；不明确的内容会单独列出。

## 使用范围

按关键词归类可能有漏项或误匹配，不会据此推断客户个人特征。


轻量部署包已默认安装 Skills 助手。在 MochiBot“设置 → MochiLab Skills 账户”验证并连接后，发送：

```text
安装 mochi-feedback-clusters
```

其他环境先[连接 Skills 助手](https://mochilab.bz/Skills/Connect.aspx?lang=zh-CN)。连接成功后不用在聊天里提供密钥。每个工作区分别连接，可使用同一个已授权会员账户。本 Skill 免费，运行本地辅助脚本需要 Python3.10+。
