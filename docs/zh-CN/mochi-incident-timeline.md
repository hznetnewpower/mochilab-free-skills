# 事件证据时间线

## 能帮你做什么

按含时区的时间整理有来源的事件记录，计算间隔并导出证据时间线。

## 直接这样说

安装后，在聊天里直接描述需求，或者贴上资料、上传文件。

```text
把这次故障的日志和记录整理成时间线，注明每条依据，算出关键事件间隔，先不要猜根因或执行修复。
```

## 你需要提供什么

提供日志或事件记录，说明所用时区；区分发生时间和收到报告的时间。

不用照着固定格式填写；缺少关键信息时，助手会用日常语言追问。

## 你会得到什么

得到带来源的时间线、事件间隔和时间不明确的记录。

助手会用清楚的文字解释结果，有生成文件时提供文件位置或下载链接；不明确的内容会单独列出。

## 使用范围

先后顺序不等于因果关系；不会自动修复、删除日志或向外发消息。


轻量部署包已默认安装 Skills 助手。在 MochiBot“设置 → MochiLab Skills 账户”验证并连接后，发送：

```text
安装 mochi-incident-timeline
```
