# 表格公式与缓存检查

## 能帮你做什么

检查XLSX公式、缓存错误和外部链接部件，明确区分静态检查与实际重算。

## 直接这样说

安装后，在聊天里直接描述需求，或者贴上资料、上传文件。

**“帮我检查这个 Excel 的公式，列出引用错误、外部工作簿引用和值得人工复核的单元格，不要改原表。”**

## 你需要提供什么

上传要检查的 Excel 文件；告诉助手重点关注哪个工作表或问题。

不用照着固定格式填写；缺少关键信息时，助手会用日常语言追问。

## 你会得到什么

得到公式位置、可见错误和外部引用线索。

助手会用清楚的文字解释结果，有生成文件时提供文件位置或下载链接；不明确的内容会单独列出。

## 使用范围

这个检查不会重新计算所有公式，也不保证财务或业务逻辑正确。


轻量部署包已默认安装 Skills 助手。在 MochiBot“设置 → MochiLab Skills 账户”验证并连接后，发送：

```text
安装 mochi-formula-audit
```
