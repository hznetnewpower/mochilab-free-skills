# 依赖升级差异检查

## 能做什么

比较两份依赖版本表，列出新增、删除、版本变化及主要版本变更。

## 操作流程

比较同一包管理器、同一依赖范围的两份精确版本表，避免把开发依赖与生产依赖混在一起。分别审核新增、删除和版本变化；主要版本提示不是兼容性结论。升级前阅读上游迁移说明、核对锁文件并运行项目检查，本工具不会安装依赖或扫描漏洞。

## 输入示例（虚构）

```json
{
  "before": {
    "alpha": "1.2.0",
    "old": "1.0.0"
  },
  "after": {
    "alpha": "2.0.0",
    "new": "1.0.0"
  }
}
```

## 输出与核对

在当前工作区生成报告及适用的产物，保留原文件。以返回结果、产物和具体检查范围为准；实时服务、远程账户操作和视觉效果需分别验证。
