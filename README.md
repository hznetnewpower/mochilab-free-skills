## Installation and costs

Choose one Skill and follow its guide for the active agent workspace. Model, hosting and external-service charges follow your configured providers. The MochiLab catalogue assistant is free; downloads from the website require your own MochiLab account connection. MochiPay Integration retains its original release and source repository; this documentation update does not modify payment services.
