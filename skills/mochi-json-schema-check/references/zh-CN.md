# JSON数据契约检查

## 能帮你做什么

按明确支持的schema子集验证JSON，逐项指出错误及不支持的关键字，避免假通过。

## 直接这样说

安装后，在聊天里直接描述需求，或者贴上资料、上传文件。

```text
帮我检查这份订单数据：数量必须是正整数，订单号不能为空，不能多出未约定的字段。把不符合规则的位置告诉我。
```

## 你需要提供什么

提供待检查的数据和业务规则；已经有校验规则文件时也可以一起上传。

不用照着固定格式填写；缺少关键信息时，助手会用日常语言追问。

## 你会得到什么

得到不符合规则的字段、支持范围及仍需补查的规则。

助手会用清楚的文字解释结果，有生成文件时提供文件位置或下载链接；不明确的内容会单独列出。

## 使用范围

目前只支持部分数据规则；不支持的检查会说明，不能把局部通过当成全部通过。
