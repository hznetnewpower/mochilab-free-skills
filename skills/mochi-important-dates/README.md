# Important Dates and Holidays / 重要日子与节日管家

Track Gregorian and lunar birthdays, anniversaries and sourced annual holidays, with advance alerts, time zones, leap-day policies and calendar export.

管理公历农历生日、纪念日和年度节假日，设置提前提醒、时区与闰日规则，导出日历。

Version 1.0.0. Python 3.10+. Start with SKILL.md; action fields are in references/input.md. Tests: python tests/smoke.py after installing scripts/requirements.txt.
