# Subscription and Renewal Desk / 订阅续费与账单管家

Track software, memberships and service renewals, calculate cancellation deadlines, forecast costs by currency and queue due notices.

管理软件、会员和服务的续费周期，计算取消期限、按币种预测开销并提醒到期。

Version 1.0.0. Python 3.10+. Start with SKILL.md; action fields are in references/input.md. Tests: python tests/smoke.py after installing scripts/requirements.txt.
