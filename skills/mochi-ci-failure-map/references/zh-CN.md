# CI失败信号归类

在指定CI日志中标出测试、依赖、编译、权限和超时信号及行号，不盲目重跑流水线。

## 操作流程

使用某一次失败任务的完整 UTF-8 日志，记录运行编号和代码版本。按报告行号回到原日志，结合步骤标题、首个异常和退出码判断因果；命中关键词只是线索。重跑部署、发布、迁移类流水线前先核对副作用，公开报告不要粘贴密钥或整段私有日志。

## 输入示例（虚构）

```json
{
  "file": "samples/ci.log"
}
```

本地处理方法见 runner.md，字段说明见 input.md。仅处理当前工作区，保留原文件，按真实输出核对结果；涉及联网、账户或发布的操作另行执行和验证。
