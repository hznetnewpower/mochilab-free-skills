# Contacts and Follow-up Desk / 联系人与跟进工作台

Import CSV/vCard contacts, review email and phone duplicates, merge records, track follow-ups and export an address book.

导入 CSV/vCard 联系人，按邮箱电话查重、合并记录、记录跟进并导出通讯录。

Version 1.0.0. Python 3.10+. Start with SKILL.md; action fields are in references/input.md. Tests: python tests/smoke.py after installing scripts/requirements.txt.
