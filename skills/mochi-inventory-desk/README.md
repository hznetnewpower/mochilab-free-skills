# Inventory and Reorder Desk / 库存进销存与补货管理

Track SKUs and warehouse movements, calculate stock and moving-average cost, and export reorder reports by currency.

管理商品和多仓库出入库流水，计算库存、移动加权成本及补货建议，按币种输出报表。

Version1.0.0 · Python3.10+ standard library · Author https://mochilab.bz

Start with SKILL.md; action fields are in references/input.md. Run python tests/smoke.py for the packaged functional tests.
