# 多来源搜索方案

## 能帮你做什么

把问题整理成精准搜索式、限定站点与原文关键词，供助手逐条检索。

## 直接这样说

安装后，在聊天里直接描述需求，或者贴上资料、上传文件。

```text
帮我查一下 OpenClaw 安装需要什么环境，优先找官方文档，先列出要查的问题和搜索方向。
```

## 你需要提供什么

告诉助手你想查什么；有指定的网站、时间范围或关键词也可以一起说。

不用照着固定格式填写；缺少关键信息时，助手会用日常语言追问。

## 你会得到什么

得到按问题整理的搜索方案；如果助手有搜索工具，可以继续检索并标明来源。

助手会用清楚的文字解释结果，有生成文件时提供文件位置或下载链接；不明确的内容会单独列出。

## 使用范围

这个功能先整理搜索方向；没有实际检索时，不会把计划说成已经查到的答案。
