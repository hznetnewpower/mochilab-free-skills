# 智能体回复回归测试

## 能帮你做什么

用已记录回复检查必含内容、禁含内容和精确答案，做可重复的回归测试。

## 直接这样说

安装后，在聊天里直接描述需求，或者贴上资料、上传文件。

```text
检查这些助手回复：每条都要说明时区，不能出现 API 密钥。把不符合要求的回复挑出来。
```

## 你需要提供什么

提供要检查的回复和明确的通过条件，例如必须出现、不得出现或必须完全一致的文字。

不用照着固定格式填写；缺少关键信息时，助手会用日常语言追问。

## 你会得到什么

得到逐条通过或失败的结果及对应原因。

助手会用清楚的文字解释结果，有生成文件时提供文件位置或下载链接；不明确的内容会单独列出。

## 使用范围

这是对已有回复的文字规则检查，不是自动测出模型的整体智力或正确率。
