# Archive and Integrity Toolbox / 压缩归档与完整性工具箱

Inspect ZIP/TAR contents, extract into new folders, create ZIPs from selected files and report per-file integrity hashes.

检查 ZIP/TAR 内容，安全解压到新目录，按指定文件生成 ZIP 并输出逐文件校验值。

Version 1.0.0. Python 3.10+. Start with SKILL.md; action fields are in references/input.md. Tests: python tests/smoke.py after installing scripts/requirements.txt.
