# 龙虾维护与迁移管家 / OpenClaw Maintenance and Migration Desk

核对指定 OpenClaw 实例的助手与绑定，生成含校验值的私有备份，检查变化并在新目录演练恢复。

Inspect one selected OpenClaw instance and its agent bindings, create verified private snapshots, compare changes and rehearse restoration in a new directory.

Runtime: Python 3.10+; installed OpenClaw CLI for live status checks. Version 1.0.1. MIT-0. See SKILL.md and references/input.md. Run tests/smoke.py with the runtime dependencies installed.
