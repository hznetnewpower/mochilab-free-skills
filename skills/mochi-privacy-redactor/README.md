# Privacy Redaction Desk / 隐私脱敏与分享检查

Scan and redact email, Chinese mobile numbers, IPs and secret fields in text, CSV and JSON, keeping originals intact.

批量检查并脱敏文本、CSV、JSON 中的邮箱、手机号、地址和密钥字段，生成新副本与处理清单。

Version1.0.0 · Python3.10+ standard library · Author https://mochilab.bz

Start with SKILL.md; action fields are in references/input.md. Run python tests/smoke.py for the packaged functional tests.
