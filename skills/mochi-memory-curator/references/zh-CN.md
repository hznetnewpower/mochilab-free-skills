# 有来源的记忆整理

## 能帮你做什么

整理用户选定且有来源的事实，发现冲突和到期内容，生成待审核记忆清单。

## 直接这样说

安装后，在聊天里直接描述需求，或者贴上资料、上传文件。

```text
帮我整理这几条准备记住的信息，找出互相矛盾或已经过期的内容，先给我看修改建议。
```

## 你需要提供什么

提供希望保留的信息和来源；临时信息可以注明有效期。

不用照着固定格式填写；缺少关键信息时，助手会用日常语言追问。

## 你会得到什么

得到可保留、存在冲突和已经过期的信息清单。

助手会用清楚的文字解释结果，有生成文件时提供文件位置或下载链接；不明确的内容会单独列出。

## 使用范围

不会扫描全部聊天，也不会未经要求直接改写记忆。
