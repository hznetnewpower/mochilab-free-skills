# RSS Subscription and Reading Hub / RSS 订阅与阅读中心

Subscribe to RSS/Atom, import and export OPML, retain read state, search saved entries and queue new-content notifications.

订阅 RSS/Atom，导入导出 OPML、保存已读状态、搜索历史条目，并生成新内容提醒。

Version 1.0.0. Python 3.10+. Start with SKILL.md; action fields are in references/input.md. Tests: python tests/smoke.py after installing scripts/requirements.txt.
