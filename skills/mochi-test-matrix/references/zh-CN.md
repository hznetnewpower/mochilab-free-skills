# 组合配置测试矩阵

## 能帮你做什么

为多个配置因素生成覆盖所有二元组合的测试矩阵，减少重复组合并明确覆盖范围。

## 直接这样说

安装后，在聊天里直接描述需求，或者贴上资料、上传文件。

```text
我的 APP 要测 Android 和 HarmonyOS、中英文、浅色和深色，帮我列一个覆盖两两组合的测试表，别漏组合。
```

## 你需要提供什么

列出需要变化的配置项，以及每项有哪些可选值。

不用照着固定格式填写；缺少关键信息时，助手会用日常语言追问。

## 你会得到什么

得到测试组合表、覆盖情况，以及应额外补测的高风险组合。

助手会用清楚的文字解释结果，有生成文件时提供文件位置或下载链接；不明确的内容会单独列出。

## 使用范围

这里只生成组合，不会运行测试；两两覆盖也不等于所有行为都已验证。
