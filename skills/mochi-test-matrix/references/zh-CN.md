# 组合配置测试矩阵

为多个配置因素生成覆盖所有二元组合的测试矩阵，减少重复组合并明确覆盖范围。

## 操作流程

把操作系统、语言、角色等独立配置列为因素，只填写产品实际支持的取值。生成后核对二元组合覆盖是否完整，并额外加入历史故障和高风险组合。矩阵只是测试用例清单，不代表测试已经运行；不支持约束语言，也不保证数量最少。

## 输入示例（虚构）

```json
{
  "factors": {
    "os": [
      "linux",
      "windows"
    ],
    "lang": [
      "en",
      "zh"
    ],
    "role": [
      "one",
      "two"
    ]
  }
}
```

本地处理方法见 runner.md，字段说明见 input.md。仅处理当前工作区，保留原文件，按真实输出核对结果；涉及联网、账户或发布的操作另行执行和验证。
