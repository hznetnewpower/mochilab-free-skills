# 表格公式与缓存检查

检查XLSX公式、缓存错误和外部链接部件，明确区分静态检查与实际重算。

## 操作流程

保留原始 XLSX，逐个定位报告中的公式单元格、缓存值、REF 错误和外部链接。缺少缓存不一定是公式错误，已有缓存也可能过期。需要真实重算时用 Excel 或兼容引擎打开并核对相关单元格和汇总；静态 XML 检查不运行宏、不跟随外链，也不验证版式。

## 输入示例（虚构）

```json
{
  "file": "samples/book.xlsx"
}
```

本地处理方法见 runner.md，字段说明见 input.md。仅处理当前工作区，保留原文件，按真实输出核对结果；涉及联网、账户或发布的操作另行执行和验证。
