# Git Project Review and Snapshots / Git 项目检查与快照

Inspect a selected Git project and commit history, distinguish staged changes and create verified private working snapshots.

查看指定 Git 项目的改动和提交记录，区分暂存内容，生成带校验清单的私有工作快照。

Version 1.0.0. Python 3.10+. Start with SKILL.md; action fields are in references/input.md. Tests: python tests/smoke.py after installing scripts/requirements.txt.
