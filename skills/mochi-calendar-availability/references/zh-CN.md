# 多人空闲时间交集

按提供的忙碌时段计算多人共同空闲时间，保留时区并检查时间范围。

## 操作流程

先明确起止窗口、最短会议时长和各参与者时区，使用带偏移量的时间。合法获取忙碌区间，并记录导出时间。生成候选空档后再核对工作时间、出行缓冲、节假日和临时占用；没有忙碌记录不等于确定有空，工具不会创建会议或发邀请。

## 输入示例（虚构）

```json
{
  "start": "2026-10-27T09:00:00Z",
  "end": "2026-10-27T12:00:00Z",
  "people": [
    {
      "busy": [
        {
          "start": "2026-10-27T10:00:00Z",
          "end": "2026-10-27T11:00:00Z"
        }
      ]
    }
  ]
}
```

本地处理方法见 runner.md，字段说明见 input.md。仅处理当前工作区，保留原文件，按真实输出核对结果；涉及联网、账户或发布的操作另行执行和验证。
