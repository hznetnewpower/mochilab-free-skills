# Multi-account Email Desk / 多邮箱邮件工作台

Connect IMAP/SMTP/POP3 accounts, sync and search mail, extract attachments, prepare and send messages, and track new-mail notifications.

接入 IMAP/SMTP/POP3 邮箱，收信搜索、处理附件、准备并发送邮件，保存新邮件提醒状态。

Version 1.0.0. Python 3.10+. Start with SKILL.md; action fields are in references/input.md. Tests: python tests/smoke.py after installing scripts/requirements.txt.
