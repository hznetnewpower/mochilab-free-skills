# Website Link and Content Audit / 网站链接与内容巡检

Crawl a bounded same-origin site and report broken links, missing fragments, duplicate titles and image alt omissions.

在指定站点内巡检链接，找出坏链、无效页内定位、重复标题和缺失图片说明，输出问题清单。

Version1.0.0 · Python3.10+ standard library · Author https://mochilab.bz

Start with SKILL.md; action fields are in references/input.md. Run python tests/smoke.py for the packaged functional tests.
