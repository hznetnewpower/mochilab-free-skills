# 依赖升级差异检查

## 能帮你做什么

比较两份依赖版本表，列出新增、删除、版本变化及主要版本变更。

## 直接这样说

安装后，在聊天里直接描述需求，或者贴上资料、上传文件。

```text
比较升级前后这两份依赖清单，告诉我新增、删除和版本变化，重点标出跨大版本的包。
```

## 你需要提供什么

提供同一项目、同一范围的升级前后依赖清单或锁定版本导出。

不用照着固定格式填写；缺少关键信息时，助手会用日常语言追问。

## 你会得到什么

得到可核对的版本差异表及后续迁移检查事项。

助手会用清楚的文字解释结果，有生成文件时提供文件位置或下载链接；不明确的内容会单独列出。

## 使用范围

不会安装依赖，也不把跨大版本直接判定为不兼容或存在漏洞。
