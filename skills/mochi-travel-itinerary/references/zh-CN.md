# 跨时区行程整理

整理用户选定的跨时区行程，检查时间重叠，并按币种分别汇总预算。

## 操作流程

按用户选择的地点和带时区起止时间排行程，费用按原币种分别汇总。当前开放时间、入境要求、交通及余位需实时核验。逐段检查重叠和转场缓冲，输入的时间不证明路程可行；工具不换汇、不订票、不付款，未落实预订和假设要明确标注。

## 输入示例（虚构）

```json
{
  "title": "Fictional day plan",
  "stops": [
    {
      "name": "Museum",
      "start": "2026-11-01T09:00:00+08:00",
      "end": "2026-11-01T10:00:00+08:00",
      "cost": "20",
      "currency": "CNY"
    },
    {
      "name": "Cafe",
      "start": "2026-11-01T10:30:00+08:00",
      "end": "2026-11-01T11:00:00+08:00",
      "cost": "5",
      "currency": "USD"
    }
  ]
}
```

本地处理方法见 runner.md，字段说明见 input.md。仅处理当前工作区，保留原文件，按真实输出核对结果；涉及联网、账户或发布的操作另行执行和验证。
