# 跨时区行程整理

整理用户选定的跨时区行程，检查时间重叠，并按币种分别汇总预算。

## 使用

先提供本功能需要的文件或参数，由助手按 `input.md` 的字段准备请求。辅助脚本只离线处理当前工作区，报告与新文件保存在 `exports/`。需要实时网页、办公账户或实际发布时，另用已有授权工具执行并核对结果。

## 输入示例（虚构数据）

```json
{
  "title": "Fictional day plan",
  "stops": [
    {
      "name": "Museum",
      "start": "2026-11-01T09:00:00+08:00",
      "end": "2026-11-01T10:00:00+08:00",
      "cost": "20",
      "currency": "CNY"
    },
    {
      "name": "Cafe",
      "start": "2026-11-01T10:30:00+08:00",
      "end": "2026-11-01T11:00:00+08:00",
      "cost": "5",
      "currency": "USD"
    }
  ]
}
```

## 验证范围

包内测试验证本地处理、错误输入、路径边界与不覆盖原文件；不表示已完成远程操作、事实核验或视觉检查。具体能力边界以 `input.md` 为准。
