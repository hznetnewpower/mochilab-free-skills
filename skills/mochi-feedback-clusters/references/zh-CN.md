# 客户反馈主题整理

按用户指定的关键词主题整理反馈，支持多标签并保留未归类项，不臆测个人属性。

## 操作流程

先约定主题和关键词，再按稳定反馈 ID 处理必要文本。匹配是忽略大小写的子串规则，应抽查多主题命中、误命中和未分类项，并记录词表变更。主题频率不是情绪、客户重要性或独立用户数，不能用少量导出代表所有客户，也不会自动回复或上传反馈。

## 输入示例（虚构）

```json
{
  "topics": {
    "speed": [
      "slow",
      "latency"
    ],
    "billing": [
      "invoice"
    ]
  },
  "feedback": [
    {
      "id": "f1",
      "text": "slow response"
    },
    {
      "id": "f2",
      "text": "invoice question"
    },
    {
      "id": "f3",
      "text": "thanks"
    }
  ]
}
```

本地处理方法见 runner.md，字段说明见 input.md。仅处理当前工作区，保留原文件，按真实输出核对结果；涉及联网、账户或发布的操作另行执行和验证。
