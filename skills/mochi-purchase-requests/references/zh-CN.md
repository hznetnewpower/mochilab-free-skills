# 采购申请与审批资料

使用精确小数计算采购申请金额，按币种汇总，并标记超过指定审批阈值的项目。

## 操作流程

每项保留唯一 ID、正数量、十进制定价、币种及报价依据，明确含税或未税。按币种汇总并核对阈值提示，但提示不是采购批准。税费、运费和优惠只有输入后才计入；采购前仍需核实供应商报价、预算和审批人，工具不会下单、比实时价格或付款。

## 输入示例（虚构）

```json
{
  "requests": [
    {
      "id": "r1",
      "quantity": 3,
      "unitPrice": "0.10",
      "currency": "USD",
      "quoteSource": "Fictional quote"
    }
  ],
  "approvalThresholds": {
    "USD": "0.20"
  }
}
```

本地处理方法见 runner.md，字段说明见 input.md。仅处理当前工作区，保留原文件，按真实输出核对结果；涉及联网、账户或发布的操作另行执行和验证。
