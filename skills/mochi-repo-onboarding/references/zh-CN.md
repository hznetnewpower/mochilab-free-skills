# 代码仓库上手地图

根据指定仓库文件清单定位技术栈、上手文档和测试入口，先理解再操作。

## 操作流程

从用户指定的仓库和版本导出文件名清单，包含隐藏文件及相关子项目。先读 AGENTS.md、README、依赖清单、锁文件和 CI 配置，再判断真实构建路径。文件名推断要标明依据，单仓多项目需分别梳理；发现安装脚本不等于已获准执行它。

## 输入示例（虚构）

```json
{
  "files": [
    "package.json",
    "README.md",
    "AGENTS.md",
    "tests/basic.test.js"
  ]
}
```

本地处理方法见 runner.md，字段说明见 input.md。仅处理当前工作区，保留原文件，按真实输出核对结果；涉及联网、账户或发布的操作另行执行和验证。
