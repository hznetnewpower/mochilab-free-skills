# 代码仓库上手地图

## 能帮你做什么

根据指定仓库文件清单定位技术栈、上手文档和测试入口，先理解再操作。

## 直接这样说

安装后，在聊天里直接描述需求，或者贴上资料、上传文件。

```text
帮我熟悉这个项目，找出它用什么技术、先读哪些文档、测试从哪里开始，先不要安装依赖或运行服务。
```

## 你需要提供什么

提供可访问的项目目录或文件清单，说明想了解哪个部分。

不用照着固定格式填写；缺少关键信息时，助手会用日常语言追问。

## 你会得到什么

得到项目上手地图和下一步阅读顺序。

助手会用清楚的文字解释结果，有生成文件时提供文件位置或下载链接；不明确的内容会单独列出。

## 使用范围

文件名只能提供线索，不能代替阅读项目文档和实际配置。
