# 社交内容批次核对

## 能帮你做什么

按用户提供的平台限制检查一批社交内容的字数与附件，保留为待发布草稿。

## 直接这样说

安装后，在聊天里直接描述需求，或者贴上资料、上传文件。

```text
帮我检查这批待发布文案，按附件里的各平台字数上限检查，再看看图片有没有漏配，先不要发布。
```

## 你需要提供什么

提供文案、目标平台、字数限制和拟配附件。

不用照着固定格式填写；缺少关键信息时，助手会用日常语言追问。

## 你会得到什么

得到超长文案、附件清单和需要调整的项目。

助手会用清楚的文字解释结果，有生成文件时提供文件位置或下载链接；不明确的内容会单独列出。

## 使用范围

不同平台计数规则可能不同，最终仍以发布页面为准；不会登录账户或自动发布。
