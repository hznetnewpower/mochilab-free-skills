# 社交内容批次核对

按用户提供的平台限制检查一批社交内容的字数与附件，保留为待发布草稿。

## 操作流程

每篇草稿保留唯一 ID、目标平台、最终文字和素材引用，并提供该平台当前字数限制。工具按 Unicode 码点计数，实际平台可能对网址、字符和账户类型采用不同规则。临界稿需在真实编辑器核对，精简不能改变事实或去掉必要出处；工具不登录、排期或发布。

## 输入示例（虚构）

```json
{
  "platformLimits": {
    "demo": 5
  },
  "posts": [
    {
      "id": "p1",
      "platform": "demo",
      "text": "hello"
    },
    {
      "id": "p2",
      "platform": "demo",
      "text": "too long"
    }
  ]
}
```

本地处理方法见 runner.md，字段说明见 input.md。仅处理当前工作区，保留原文件，按真实输出核对结果；涉及联网、账户或发布的操作另行执行和验证。
