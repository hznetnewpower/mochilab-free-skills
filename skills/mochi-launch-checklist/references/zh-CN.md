# 产品上线证据清单

检查产品上线必需任务是否完成且有证据，列出阻塞项供负责人判断。

## 操作流程

按本次真实发布范围建立清单，区分必需和可选任务，给出状态及证据位置。必需项同时需要完成状态与非空证据，但仍须查看证据本身，不能把填了文字当作通过。核对回滚、支持负责人、已知限制和升级路径；工具不部署、不发公告，也不是合规证明。

## 输入示例（虚构）

```json
{
  "tasks": [
    {
      "id": "smoke",
      "status": "done",
      "evidence": "Fictional test receipt"
    },
    {
      "id": "rollback",
      "status": "pending"
    }
  ]
}
```

本地处理方法见 runner.md，字段说明见 input.md。仅处理当前工作区，保留原文件，按真实输出核对结果；涉及联网、账户或发布的操作另行执行和验证。
