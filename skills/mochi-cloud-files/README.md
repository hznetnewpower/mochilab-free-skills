# WebDAV Cloud File Desk / WebDAV 网盘工作台

Connect a WebDAV drive, list and compare a directory, upload or download files, check versions and produce integrity hashes.

连接 WebDAV 网盘，查看文件、比较目录、上传下载，按文件版本处理冲突并生成校验值。

Version 1.0.0. Python 3.10+. Start with SKILL.md; action fields are in references/input.md. Tests: python tests/smoke.py after installing scripts/requirements.txt.
