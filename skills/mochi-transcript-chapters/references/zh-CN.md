# 转录文稿章节整理

把拟定的视频章节与转录片段ID关联，检查时间范围并导出时间戳章节表。

## 操作流程

先取得授权转写及带唯一 ID 的时间段，标题必须依据实际文本。每个章节关联存在的片段 ID，并按真实话题转折检查边界和时间顺序。导出后对照音视频核对最后时间点；引用关系通过不等于摘要准确，工具不会获取视频、生成转写或发布章节。

## 输入示例（虚构）

```json
{
  "segments": [
    {
      "id": "s1",
      "start": 0,
      "end": 60
    },
    {
      "id": "s2",
      "start": 60,
      "end": 120
    }
  ],
  "chapters": [
    {
      "start": 0,
      "title": "Opening",
      "sourceIds": [
        "s1"
      ]
    },
    {
      "start": 60,
      "title": "Example",
      "sourceIds": [
        "s2"
      ]
    }
  ]
}
```

本地处理方法见 runner.md，字段说明见 input.md。仅处理当前工作区，保留原文件，按真实输出核对结果；涉及联网、账户或发布的操作另行执行和验证。
