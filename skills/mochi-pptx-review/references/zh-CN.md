# 演示稿文本密度检查

检查PPTX各页文字量、空文本页和字符预算，为实际排版检查提供线索。

## 操作流程

根据演示场景设定每页文字预算，按报告定位文字偏多的页面并提出精简建议。技术附录与标题页不能套同一编辑判断，纯图片页没有 XML 文字也可能正常。裁切、重叠、对比度和图表仍须渲染或 PowerPoint 检查，不能用字数报告替代视觉验收。

## 输入示例（虚构）

```json
{
  "file": "samples/slides.pptx",
  "maxCharsPerSlide": 100
}
```

本地处理方法见 runner.md，字段说明见 input.md。仅处理当前工作区，保留原文件，按真实输出核对结果；涉及联网、账户或发布的操作另行执行和验证。
