# Document Templates and Batch Output / 文档模板与批量出稿

Generate notices, certificates and business documents from DOCX, text or HTML templates, validate fields and retain Word run formatting.

从 DOCX、文本或 HTML 模板批量生成通知、证明和业务文档，检查缺漏字段并保留 Word 排版。

Version 1.0.0. Python 3.10+. Start with SKILL.md; action fields are in references/input.md. Tests: python tests/smoke.py after installing scripts/requirements.txt.
