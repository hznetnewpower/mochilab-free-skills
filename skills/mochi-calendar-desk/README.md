# Calendar and Agenda Desk / 日程日历工作台

Import ICS calendars, expand recurring events, inspect conflicts, create meeting files and transfer CalDAV resources with version checks.

导入 ICS 日历，展开重复事件、查看日程冲突，创建会议文件并按版本同步 CalDAV。

Version 1.0.0. Python 3.10+. Start with SKILL.md; action fields are in references/input.md. Tests: python tests/smoke.py after installing scripts/requirements.txt.
