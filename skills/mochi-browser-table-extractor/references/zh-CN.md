# 网页表格采集

## 能帮你做什么

从已授权浏览器保存的页面提取指定表格，保留表头、中文及来源信息，生成CSV。

## 直接这样说

安装后，在聊天里直接描述需求，或者贴上资料、上传文件。

```text
把这个网页里的价格表整理成 CSV，保留表头、商品名称和原网页链接。
```

## 你需要提供什么

提供网页链接或保存的网页文件；一页有多张表时，说明要哪一张。

不用照着固定格式填写；缺少关键信息时，助手会用日常语言追问。

## 你会得到什么

得到可下载的表格文件，以及提取范围和未能读取的内容。

助手会用清楚的文字解释结果，有生成文件时提供文件位置或下载链接；不明确的内容会单独列出。

## 使用范围

只能提取实际读取到的表格；动态加载、滚动列表或图片表格可能需要额外处理。
