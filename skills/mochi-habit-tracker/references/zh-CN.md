# 个人习惯完成记录

按用户记录计算完成天数、截至指定日期的连续天数及窗口完成率。

## 操作流程

先约定完成一次的含义、用户本地日期、截止日和统计窗口，同一天重复记录只计一次。连续天数描述的是已记录日期，不代表动机或健康状态。缺记录可能是漏记，未来或窗口外日期应核对；工具不做行为画像、医疗判断或自动提醒，也不擅自改历史数据。

## 输入示例（虚构）

```json
{
  "dates": [
    "2026-10-25",
    "2026-10-26",
    "2026-10-27",
    "2026-10-27"
  ],
  "asOf": "2026-10-27",
  "windowDays": 7
}
```

本地处理方法见 runner.md，字段说明见 input.md。仅处理当前工作区，保留原文件，按真实输出核对结果；涉及联网、账户或发布的操作另行执行和验证。
