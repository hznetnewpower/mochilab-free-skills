# Word批注与修订证据地图

整理DOCX批注及对应段落，列出插入和删除修订，检查丢失的批注定义，保留原文档。

## 操作流程

使用保留批注和修订的 DOCX 原件，按批注 ID、定义和段落锚点建立对应关系。分开查看插入文字与删除文字，避免把已删除内容当作现行正文。缺失批注定义需回原件调查；线程、已解决状态和版式仍需 Word 核对，工具不接受或拒绝修订。

## 输入示例（虚构）

```json
{
  "file": "samples/review.docx"
}
```

本地处理方法见 runner.md，字段说明见 input.md。仅处理当前工作区，保留原文件，按真实输出核对结果；涉及联网、账户或发布的操作另行执行和验证。
