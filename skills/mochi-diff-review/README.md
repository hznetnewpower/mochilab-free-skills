# File Diff and Delivery Review / 文件差异与交付验收

Compare text, JSON, keyed CSV and directories, create delivery manifests and verify file additions, changes and hashes.

比较文本、JSON、CSV 和目录差异，生成交付文件清单，核对新增、修改、缺失及 SHA256 校验值。

Version1.0.0 · Python3.10+ standard library · Author https://mochilab.bz

Start with SKILL.md; action fields are in references/input.md. Run python tests/smoke.py for the packaged functional tests.
