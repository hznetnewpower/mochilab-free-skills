# PDF 文件工具箱 / PDF Toolbox

合并、拆分、选页、排序、旋转和压缩 PDF，支持图片转 PDF、页面预览及空白页检查。

Merge, split, select, reorder, rotate and compress PDFs; convert images, render previews and inspect blank pages.

Runtime: Python 3.10+, pypdf 6.10+, pypdfium2 5.14+, Pillow 12.3+

Version:1.0.0. License:MIT-0. Read SKILL.md and references/input.md. Copy samples into the active workspace before using request.json.
